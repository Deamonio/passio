# LLM-only DDR/DCR 평가 보고서

## 1. 실험 개요
- 대상 파이프라인: Gemma-only (LLM-only)
- 데이터셋: 120문항
- 반복 실행: 10회
- 총 실행 수: 1,200회
- 기준 컬럼: AI_정답
- 정렬 키: index

## 2. DDR/DCR 정의
- DDR (Deterministic Decision Reproducibility Rate): 동일 문항 반복 실행 시 답변이 일치한 비율
- DCR (Decision Change Rate): 동일 문항 반복 실행 시 답변이 바뀐 비율
- 관계식: DCR = 1 - DDR

## 3. 핵심 결과

- DCR: 0.0000 (0/120)
- Empty answer cases: 0

해석:
- 120개 모든 문항이 10회 실행 동안 답변 불변
- LLM-only 구성에서 결정성/재현성은 매우 높음
